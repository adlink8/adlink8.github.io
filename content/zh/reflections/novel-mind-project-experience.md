## 2. 人机协同投入产出与杠杆效应 (Human-AI Leverage)

基于权威会话事件数据库的统计：

```
用户输入 (3,203 轮) ───[ 1 : 7.3 杠杆比 ]───► AI 自主执行 (23,318 轮)
  ├── 平均 1,332 字符/次 (架构级约束)          ├── 12.6 万次模型深度推理 (Reasoning)
  └── 零废话、高信息密度指示                   ├── 1.7 万次自动化终端命令 (Exec)
                                               └── 3,738 次精准代码重构 (Edit)
```

- **高密度输入**：用户端没有琐碎的聊天式交互，每次输入平均达 **1,332 字符**，均属于架构设计、验收标准、GSD 任务卡与边界规范。
- **自主放大效应**：单次系统指令驱动 AI 自主进行代码探测、推理、编辑、测试验证与 Git 提交，形成 **1:7.3 的轮次放大** 与 **1:18 的操作动作放大**。

### 🔍 亚健康会话根因剖析（C/D/F 级会话特征）
全局 1,667 场会话中，仅有 3.4% 判定为亚健康（55 场 C 级、39 场 D 级、7 场 F 级）：
- **核心病因**：死循环重试（平均 22.5~74.7 次重试）与巨型文件导致的上下文过载（Compaction 2.9~9.0 次）。
- **解法沉淀**：引入单次重试熔断、强制上下文清理与 Claude Worktree 物理隔离，8 月彻底解决了长会话退化问题。

## 6. 五大核心认知沉淀 (Lessons Learned)

1. **"存在 ≠ 集成"**：前端页面有按钮 / 入口，不代表后端有可用接口；必须通过端到端契约测试进行闭环验证。
2. **"不重新消耗一次全部模型费用"**：依赖局部哈希与 Checksum 机制，优先复用已生成的底层资产，仅对失效模块增量重跑。
3. **验收三级跃迁**：从简单的"功能可用（Demo级）"，跃迁至"体验级"，最终收敛于"质量级（带断言、幂等性与可回滚）"。
4. **GSD 规划即基建**：将权威角色与系统级规则固化在规范中，模型偏离时能快速根据规则自我纠偏。
5. **巨型文件拆分范式**：采用"模块重导出兼容层 + 公共 Import 面不变"的渐进式重构手法，实现零破坏性拆解。
